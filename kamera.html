📖 Panduan Cara Bermain & Fitur Lengkap Website

📹 1. Cara Menyalakan Kamera

• Klik Allow / Izinkan saat browser meminta akses webcam.

• Pastikan posisi tangan berada di depan kamera dengan pencahayaan ruangan yang memadai.

• Website secara otomatis mendeteksi hingga 4 Tangan sekaligus secara real-time (60 FPS).

🎮 2. Panduan Lengkap Mode & Gestur Tangan

👤 Mode 1/4: Panggil Nama Custom (TTS AI Voice Synthesizer)
Tunjukkan 0 jari (Tinju 👊) hingga 5 jari (🖐️) ke kamera. Suara AI Bahasa Indonesia akan memanggil nama Anda secara otomatis. Anda bisa mengedit nama custom di panel sebelah kanan.

📸 Mode 2/4: Photo Blur Trend (Portrait Bokeh Depth Effect & MP3 Audio Player)
Tunjukkan pose ✌️ 2 Jari (Telunjuk + Tengah) ke kamera untuk memicu bokeh depth blur latar belakang & pemutar musik MP3 otomatis. Dilengkapi tombol Upload MP3 Custom, Mute/Play Toggle, & Auto-Sync Audio.

🌌 Mode 3/4: 3D Animasi Kosmik (NovaSpark 3D Engine Pro)
• 🖐️ Tangan 1 Master: Mengunci kontrol posisi & rotasi 3D real-time.
• 🚀 Tangan Maju / 5 Jari Open: Mengembangkan skala secara halus (*fluid lerp*) & meledakkan Cosmic Supernova Burst.
• 🛡️ Tangan Mundur: Skala partikel stabil di baseline normal (`1.0`), tidak akan menciut / kaku.
• ☝️ 1 Jari (Telunjuk): Kontrol rotasi presisi 360° tampilan 3D di udara.
• ✌️ 2 Jari: Mengatur kemiringan rotasi Z-Plane Roll.
• 👋 Kibasan Tangan: Usap horizontal tangan di udara untuk berpindah ke bentuk 3D berikutnya!
• 💫 15 Bentuk 3D Pro: REALISTIC LOVE 3D (Rainbow Rays & Star Dust), STAR FORGE 3D, BUMI TATA SURYA, PARTIKEL MZKYZAK, GALAXY, NEBULA, SATURN, LOTUS, JELLYFISH, TORUS, TORNADO, DOUBLE HELIX, CUBE, BUTTERFLY, PEACH BLOSSOM, MZKYZAK STAR.

🎨 Mode 4/4: Hand Tracking Filter Portal (RetroLens Engine Pro)
• 👊 Dual Fist (2 Tinju 👊👊 / Key `C`): Beralih antara 3D Mesh Portal Mode dan 2D Quad / Bowtie Mode.
• 👌 Cubit / Touch (Jempol + Kelingking / Sentuh 2 Telunjuk / Key `N` & `P`): Ganti ke filter retro berikutnya/sebelumnya.
• 🎯 Animasi Ujung Jari: Penanda lingkaran neon bercahaya & gelombang radar animasi berdenyut pada setiap ujung jari.
• ✨ 14 Filter Retro: DUAL-TONE, THERMAL, SKETCH, PIXELATE, GLITCH, INVERT, RED-CHANNEL, EDGE CANNY, BLUR, CARTOON, RAINBOW WAVE, MONO, NEON, SEPIA.

🎛️ 3. Panduan Tombol & Toggle Control UI

• 📖 Toggle Panduan (Header Kiri): Membuka & menutup jendela modal panduan ini kapan saja.

• 🌙 / ☀️ Toggle Theme (Header Kiri): Berganti instan antara Mode Gelap (Cosmic Dark) dan Mode Terang (High Contrast Light Mode) dengan penyesuaian warna teks otomatis.

• 🎮 Toggle Tab Mode (Header Center): Berpindah cepat antar 4 Mode Utama (Mode 1, Mode 2, Mode 3, Mode 4).

• 🔊 / 🔇 Toggle Suara AI (Sidebar Mode 1): Mengaktifkan atau mematikan fitur panggilan nama otomatis (TTS Synthesizer).

• 📷 Toggle Select Kamera (Sidebar): Memilih & beralih input antar perangkat webcam/kamera USB yang terhubung.

• 👊 Toggle Mesh 3D / 2D Quad (Mode 4): Gunakan tombol Toggle Mesh/Quad Mode, gestur 2 Tinju 👊👊, atau tekan tombol `C` pada keyboard.

• 🎨 Carousel Filter Bar (Mode 4): Klik langsung pada pill filter atau gunakan tombol panah untuk memilih 14 efek visual retro.

⌨️ 4. Shortcut Keyboard

• `N` : Ganti ke Filter Selanjutnya (Next Filter Mode 4)

• `P` : Ganti ke Filter Sebelumnya (Prev Filter Mode 4)

• `C` : Toggle Mode 3D Mesh / 2D Quad (Mode 4)

• `S` : Ambil Screenshot & Simpan Foto HD Instant (Mode 4)

✨ 5. Manfaat & Fitur Utama Web App

• Interaksi Bebas Sentuh (Touchless Control): Mengontrol visual, rotasi 3D, dan filter kamera hanya dengan gerak-gerik gestur tangan tanpa menyentuh layar.

• Super Smooth 60 FPS Engine: Pemrosesan gambar & tracking dilakukan 100% lokal di browser menggunakan WebGL GPU acceleration tanpa delay.

• Multi-Hand Tracking (Up to 4 Hands): Mendeteksi hingga 4 tangan sekaligus dengan pemisahan kontrol (Tangan 1 Master Referensi Rotasi).

• Dual Theme Smart Contrast: Teks dan elemen UI otomatis berubah ke kontras tinggi saat berpindah ke Mode Terang.
