🎮 Cara Bermain & Mode Gestur Tangan
👤
Mode 1/4: Panggil Nama
Tunjukkan 0 jari (Tinju 👊) hingga 5 jari (🖐️) ke kamera untuk memicu panggil nama custom via suara TTS otomatis. Nama dapat dikustomisasi pada sidebar.
📸
Mode 2/4: Photo Blur Trend
Tunjukkan pose ✌️ 2 jari (Telunjuk + Tengah) ke kamera untuk memicu efek bokeh depth blur latar belakang secara otomatis. Area tubuh & wajah tetap tajam.
🌌
Mode 3/4: 3D Animasi Kosmik
Tangan 1 Master: Kontrol rotasi 3D real-time. Tangan maju / 5 Jari meledakkan Supernova Burst, tangan mundur stabil (baseline 1.0). Kibas tangan untuk ganti 15 Bentuk 3D.
🎨
Mode 4/4: RetroLens Filter Portal
Gunakan 2 Tinju 👊👊 / Key `C` untuk toggle 3D Mesh / 2D Quad. Cubit/sentuh telunjuk (Key `N` & `P`) untuk memilih 14 Filter Retro dengan animasi radar ujung jari.
📝 Deskripsi Website Ini

Hand Tracking adalah teknologi visual interaktif yang melacak pergerakan dan posisi 21 titik koordinat sendi tangan manusia melalui kamera web secara real-time. Website ini menggabungkan model MediaPipe Hands, TensorFlow BlazeFace, dan Three.js Engine untuk menghasilkan manipulasi visual partikel 3D dan interaksi bebas sentuh yang responsif.

  • Deteksi Wajah: Melacak posisi area wajah pengatur fokus visual secara real-time.
  • Deteksi Tangan: Menggunakan MediaPipe Hand Pose untuk melacak koordinat posisi telapak dan jari tangan secara seimbang dan presisi.
  • Deteksi Gestur: Mengenali berbagai pola gerakan dan pose jari tangan untuk mengontrol efek animasi serta filter kamera secara interaktif.
